# 🌊 Criação de projeto aula 11
Este projeto em **Python** foi desenvolvido para praticar o ciclo **Entrada → Processamento → Saída**.  

## 📋 Objetivo -  monitoramento de um reservatório de água, exibindo alertas com cores diferentes, conforme o nível de água do reservatório.

## ⚙️ Funcionalidades

  - Nível 5 (Muito alto) 💧
  - Níveis 4 e 3 (alto e médio) ⚖️
  - Nível 1 (Muito Baixo -crítico) 🚨
---

🛠️ Tecnologias Utilizadas
Python 🐍
